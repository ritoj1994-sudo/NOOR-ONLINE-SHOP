# NOOR GODOWN MANAGER

Standalone Android stock register for a single user.

- Bangla interface
- Bangladesh Taka (৳)
- Add products with opening quantity, purchase price and sale price
- Record stock IN and OUT
- Current stock and stock valuation
- Transaction history and simple totals
- Data stored locally on this device using AsyncStorage

## Build
Run the GitHub Actions workflow **Build NOOR Godown Manager APK**. Download the artifact named **NOOR-GODOWN-MANAGER-APK**.

Important: this first version stores records on the phone only. Uninstalling or clearing app data can remove records; export/backup and cloud sync are not included yet.
